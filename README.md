# 笑联Plus (XiaoLianPlus)

智慧笑联（`com.xiaolian.prometheus`）体验增强 Xposed 模块，基于 LibXposed (API 102) 开发。

---

## ✨ 核心特性

- **⚡ 秒开即用**：跳过开屏等待与广告，冷启动直接进入主界面。
- **💧 饮水机助手**：
  - **收藏置顶**：常用机位一键星标，优先排在最前面。
  - **长按改名**：长按机位名称即可自定义备注（如“4楼水房”）。
  - **列表加载时直接扫码**：加载转圈时不锁死屏幕，右下角扫码随时可点。
- **🎯 启动直达策略**：
  - 支持设置冷启动后自动打开「扫一扫」或直接跳转到「饮水机/指定服务」。
- **🎨 原生风格设置页**：
  - 无缝嵌入在应用「我的」页面中，无需多余桌面图标，即开即用。

---

## 📱 适配环境

- **宿主版本**：智慧笑联 **v1.5.7** 及以上
- **框架支持**：LSPosed / LSPosed (Ipatch) 等 LibXposed API 102 兼容框架
- **系统要求**：Android 7.0 (API 24) 及以上

---

## 🚀 使用说明

1. 在 LSPosed 管理器中激活本模块，作用域勾选 **智慧笑联**；
2. 强行停止并重新打开智慧笑联；
3. 进入应用右下角 **「我的」** 页面，点击列表中的 **「笑联Plus 设置」** 即可按需开启功能。

---

## 🛠️ 本地编译

```bash
git clone https://github.com/yilink1/XiaoLianPlus.git
cd XiaoLianPlus
./gradlew assembleRelease
```
*构建产物路径：`app/build/outputs/apk/release/`*
