# 笑联Plus

智慧笑联（`com.xiaolian.prometheus`）体验增强 Xposed 模块，基于 LibXposed (API 102) 开发

</div>

---
 
## 核心特性
 
- **快速启动**：跳过开屏等待与广告，冷启动后直接进入主界面
- **饮水机增强** 
  - **常用设备置顶**：点击星星收藏置顶，支持联网及公共水机
  - **设备名称自定义**：长按水机名称修改自定义备注与高亮颜色（如“4层东YS401”）
  - **默认进入全部收藏**：打开饮水机页面时，有收藏则优先展示“全部收藏”独立视图
  - **加载期间支持扫码**：页面正在加载列表时，依然可以直接点击右下角扫码，无需等待加载完成
- **设备使用与结算**
  - **跳过二次确认**：点击「开始使用」后自动确认「确认开始使用」弹窗
  - **长按快速结算**：长按滑块 0.5 秒即可结算，无需费力向右拖动
  - **长按按钮主题**：提供「轻质玻璃」、「机械齿轮」等多款个性化结算外观，带动态预览选择器
- **快捷与启动** 
  - **长按图标快捷**：桌面长按 App 图标弹出动态快捷方式，支持添加常用设备与扫一扫，内置自定义编排器自由调整顺序
  - **启动应用直达**：点击图标打开应用时，支持自动直达自选快捷设备或扫一扫界面，兼顾冷启动与后台秒开
- **原生设置页集成** 
  - 设置功能直接集成至应用「我的」页面，纯净无广告，打开应用即可按需配置
- **高级与调试**
  - **详细调试日志**：默认关闭以避免日志刷屏，排查问题时开启以记录完整运行日志

 
***
 
## 适配环境
 
- **宿主版本**：智慧笑联 **v1.5.7** 及以上
- **框架支持**：LSPosed / LSPosed (Ipatch) 等 LibXposed API 102 兼容框架
- **系统要求**：Android 7.0 (API 24) 及以上

 
***
 
## 使用说明
 
1. 在 LSPosed 管理器中激活本模块，作用域勾选 **智慧笑联**
2. 强行停止并重新打开智慧笑联
3. 进入应用右下角 **「我的」** 页面，点击列表中的 **「笑联Plus 设置」** 即可按需开启功能

 
***
 
## 本地编译
 
```bash
git clone https://github.com/yilink1/XiaoLianPlus.git
cd XiaoLianPlus
./gradlew assembleRelease
```
 
构建产物路径：`app/build/outputs/apk/release/`
